## نمونه‌های ایمپورت

| فایل | کاربرد |
|---|---|
| `samples/numbers-sample.csv` | ایمپورت شماره با هدر فارسی |
| `samples/numbers-sample.xlsx` | همان داده‌ها به فرمت اکسل |
| `samples/modems-sample.csv` | ایمپورت مودم |
| `samples/modems-sample.xlsx` | همان داده‌ها به فرمت اکسل |

ستون‌های شماره: `شماره`, `قیمت`, `اپراتور`, `تاریخ تولد`, `توضیحات`

ستون‌های مودم: `برند`, `مدل`, `قیمت`, `موجودی`, `توضیحات`
